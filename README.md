## 🔍 Visão Geral

O **Projeto React-Native** é uma estrutura de aplicativo mobile desenvolvida com fins educacionais, apresentando boas práticas em arquitetura React Native e integração com Firebase. Ele fornece uma base sólida para construção de apps voltados ao bem-estar e acompanhamento de hábitos.

### Por que usar este projeto?

Este projeto visa facilitar o aprendizado e o desenvolvimento rápido de apps voltados à saúde e mudança de comportamento.

**Funcionalidades principais:**

- 🎯 **Modelos de Dados:** Entidades bem estruturadas para hábitos, sono, vícios e motivação, possibilitando experiências personalizadas.
- 🔗 **Integração com Firebase:** Sincronização de dados em tempo real, autenticação e backend robusto.
- 🖌️ **Componentes de UI personalizados:** Como `VicioCard` e `CustomNavBar`, garantindo uma interface envolvente.
- ⚙️ **Arquitetura modular:** Navegação clara, autenticação e gerenciamento de estado organizados.
- 🌐 **Compatibilidade multiplataforma:** Funciona em iOS, Android e Web utilizando React Native com Expo.

## 🚀 Primeiros Passos

### ✅ Pré-requisitos

Antes de começar, certifique-se de ter instalado:

- **Linguagem:** TypeScript  
- **Gerenciador de Pacotes:** npm

---

### 📦 Instalação

Clone o repositório e instale as dependências:

```bash
# Clone o repositório
git clone https://github.com/Claudio-Arauj/React-Native-Project

# Acesse o diretório
cd React-Native-Project

# Acesse o diretório do sistema
cd sistema

# Instale as dependências
npm install
```


### ▶️ Uso

Para iniciar o projeto localmente:

```bash
npx expo start
```
